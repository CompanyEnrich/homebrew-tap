# CompanyEnrich Homebrew tap

```sh
brew install companyenrich/tap/companyenrich
```

This installs the [CompanyEnrich CLI](https://github.com/CompanyEnrich/companyenrich-cli) on macOS and Linux, with shell completions for bash, zsh and fish.

To update it later:

```sh
brew upgrade companyenrich
```

The formula is generated by the CLI's release script, so changes to it belong in that repo.
